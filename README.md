# WebCraft 生存模式

浏览器版“我的世界”生存模式：无限程序化地图、昼夜循环、生物、合成、熔炉、存档。

## 运行

```bash
npm install
npm run dev      # 开发服务器，浏览器打开终端里显示的地址
npm run build    # 生产构建到 dist/
npm test         # 单元测试
```

## 功能

- 无限世界：按种子确定性生成，区块在 Web Worker 中生成与网格化，随玩家移动加载/卸载
- 生物群系：平原、森林、桦木森林、针叶林、雪原、沙漠、山地、海洋、沙滩、河流；洞穴、矿石、树木、花草
- 光照：天空光 + 方块光（火把、熔岩、熔炉）传播，平滑光照与环境光遮蔽
- 生存：生命值、饥饿值、饱和度、氧气、摔落伤害、溺水、熔岩、仙人掌
- 挖掘时间按硬度与工具计算，工具耐久，矿石需对应等级的镐
- 合成（2x2 / 3x3 工作台）、熔炉烧炼、箱子、床（跳过夜晚/重生点）、水桶/岩浆桶、锄地种小麦、树苗生长、树叶凋零
- 流体流动（水 7 格、岩浆，水岩浆生成黑曜石/圆石）、沙子沙砾下落
- 生物：猪、牛、羊；夜晚/黑暗处刷新僵尸（白天燃烧）和苦力怕（爆炸破坏地形）
- 声音：全部音效离线合成（Web Worker 预渲染，每种 3-4 个变体）——不同材质的脚步/挖掘/放置声、动物与僵尸的共振峰发声、爆炸、水花、游泳等；HRTF 3D 定位；洞穴里混响更大、水下声音变闷；环境音（风声、白天鸟叫、夜晚虫鸣、洞穴怪声与滴水、流水、熔岩）；C418 风格的生成式钢琴背景音乐（暂停菜单可调主音量与音乐音量）
- 存档：IndexedDB 自动保存（世界、玩家、修改过的区块、箱子/熔炉、动物）

## 操作

1-9/滚轮 切换 · E 物品栏 · Q 丢弃 · F3 调试 · F1 隐藏界面 · Esc 暂停

注：浏览器中 Ctrl+W 会关闭标签页，建议用双击 W 疾跑。世界高度为 128 格。
